# Code conventions

Rules for writing code in this repo. `CLAUDE.md` points here, so read this before changing code.

## PHP / Laravel

- **Don't access the container as an array** (`$this->app['router']`, `app()['config']`). `ServiceProvider::$app` is typed as the `Illuminate\Contracts\Foundation\Application` interface, which doesn't extend `ArrayAccess`, so Intelephense reports P1006 even though it works at runtime. Use the facade (`Route::aliasMiddleware(...)`), `$this->app->make(Router::class)`, or inject the dependency into `boot()`.

## API responses

Every endpoint uses the same envelope (SPEC 04).

| Case | Status | Body |
|---|---|---|
| Single object | 200/201 | `{ "data": { ... } }` |
| List | 200 | `{ "data": [ ... ] }` |
| Paginated list (future) | 200 | `{ "data": [...], "links": {...}, "meta": {...} }` via `Resource::collection($paginator)` |
| Composite (login/register) | 200/201 | `{ "data": { "token": "...", "user": { ... } } }` |
| Action with no resource | 200/202 | `{ "message": "..." }` |
| Delete / logout | 204 | no body |
| Error | 4xx/5xx | Laravel default: `{ "message": "..." }`, plus `"errors": { "field": [...] }` on 422 |

- **Keys are `snake_case`**, in responses and in request bodies.
- **The HTTP status carries success or failure.** No `success`, `status` or `code` fields.
- **Timestamps are ISO-8601 UTC with a `Z` suffix** (`toIso8601ZuluString()`), or `null`.
- **Enums are sent as their raw value.**
- **Bodies are built with API Resources**, so they get the `data` wrapper and Scramble infers them. `{ "message": ... }` bodies are the only exception.
- `test_success_responses_use_the_envelope` in `tests/Feature/Docs/OpenApiDocumentTest.php` fails if a 2xx JSON response in the exported document has no top-level `data` or `message`.

## API documentation (Scramble)

The OpenAPI document is generated by [Scramble](https://scramble.dedoc.co/) and is the contract the client apps generate their code from.

- **Follow Scramble's documentation** (https://scramble.dedoc.co/) when documenting endpoints. Use its mechanisms, not hand-written OpenAPI or another tool. Check the docs for the installed version (`composer show dedoc/scramble`) before adding a workaround.
- **Rely on inference first.** Scramble already reads FormRequests, API Resources and return types, and infers 401 from `auth:sanctum` and 422 from validation. Only add what it can't infer:
  - `#[Group('<Module>')]` on each controller, so each module gets one tag;
  - a PHPDoc summary line, a blank line, then a description on each method;
  - `@unauthenticated` on guest endpoints, because bearer security is declared globally;
  - `@throws` for statuses it misses (`ThrottleRequestsException` → 429, `ModelNotFoundException` → 404);
  - `@response` when an inferred body is wrong;
  - `@example` on each resource field and validation rule.
- **Document every endpoint completely:** a group, a summary, every response status and examples.
- **Cross-cutting tweaks** go in the Scramble document transformer in `app/Providers/AppServiceProvider.php`, not in individual controllers.
- **Re-export in the same PR** after any API change: `php artisan scramble:export --path=docs/openapi/v1.json`. If you don't, the drift test in `tests/Feature/Docs/OpenApiDocumentTest.php` fails.
